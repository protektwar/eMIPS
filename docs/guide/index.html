eMIPS user guide

eMIPS is a MIPS32 emulator for learning: you write (or load) a program, run it on a model that behaves like a real MIPS32 processor, and watch what happens inside — how each instruction is decoded, what the ALU computes, how the five pipeline stages overlap, where and why the pipeline stalls.

The guide is written for students; teachers will find a section of their own in Phase 6.

Looking for something? What's in eMIPS lists every feature, where it is in the window and on the command line, the section that explains it and the labs that use it.
